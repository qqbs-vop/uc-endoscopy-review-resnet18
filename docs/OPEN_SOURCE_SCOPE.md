# Release scope: runnable model

This release provides a trained ResNet-18 model for ulcerative colitis endoscopic image analysis.
The Windows release contains the executable, its runtime dependencies and the same model weights.
Excluded: research images, sample images, screenshots, CAM examples, masks, raw or cleaned datasets, original split manifests, patient-level records, study predictions, other trained models, optimizer checkpoints, private server scripts, credentials and the full statistical reproduction pipeline.
The scope supports model use and new local training. It does not claim a complete reproduction of all study tables or figures.
Original study files and private archives are preserved.
